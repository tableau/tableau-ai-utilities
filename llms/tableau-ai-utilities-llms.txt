# Tableau AI Utilities

> Skills that change how Tableau Agent authors, checks, and ships workbooks — and how you customize that default behavior.

Tableau Agent in Tableau Studio loads a skill when the short description at the top of `SKILL.md` matches the ask. The body is how to do the work. Supporting notes stay next to that file so the agent opens them only when the skill says to.

Installable skills from this catalog go in `My Tableau Repository (Beta)/Tableau Agent/Skills/`. Reload with `/reload-skill`. Skills labelled **EDIT WITH CAUTION** are tuned to Tableau Studio; changing them is not recommended. Place a same-name folder in the skills root to override an overridable skill.

This file is a curated index. Each corpus is SKILL.md plus the README when-to-use sections (not walkthroughs or reference catalogs). Machine-readable catalog: [catalog.json](https://tableau.github.io/tableau-ai-utilities/catalog.json). Generated from `tableau-studio-skills/` and `tableau-mcp-skills/`; do not edit by hand.
