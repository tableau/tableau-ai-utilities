Publishing Checklist Reference

Complete pre-publish checklist organized by domain. Each item is tagged with detectability status indicating whether the Desktop agent can check it via tools, or whether it must be reported as a user-verified item.

Data Source(s)​

General​

CheckDetectable?Method / Limitation
Descriptive datasource name (not "Sample - Superstore" left as default)Partiallist-workbook-datasources returns the name; pattern-match against known defaults
Embedded credentialsNoNot exposed via any Desktop tool. Advise user to verify in Data > [datasource] > Edit Connection.
Refresh schedule configured (for extracts)NoServer/Cloud-side configuration. Remind user to set post-publish.
Data freshness policy (for live connections)NoServer/Cloud-side configuration. Remind user to set post-publish.
Remove/hide duplicative or unused fieldsYeslist-available-fields cross-referenced with sheet usage (see Checklist Category 1 in SKILL.md)
Logical/physical table relationships appropriatePartialCan see table count and relationship fields from inventory; cannot judge business appropriateness. Flag multi-table datasources for user review.

Published Datasource Metadata (Post-Publish Reminders)​

These cannot be verified pre-publish from Desktop. Include as a reminder checklist:

  • Create Lens(es) if applicable
  • Add datasource description
  • Document limitations
  • Document entry criteria (who should use this data, for what)
  • Document use cases
  • Verify lineage is visible
  • Confirm refresh schedule for Tableau extract
  • Confirm refresh schedule for external ETL/ELT

Fields & Calculations​

CheckDetectable?Method / Limitation
Calculations validated for accuracy at different aggregation levelsNoRequires domain knowledge and manual testing. Remind user.
Calculations are not more complex than necessaryPartialCan flag deeply nested calcs (3+ dependency levels) or calcs with 5+ function calls. Cannot judge business necessity.
Row-level and aggregate calculations used appropriatelyPartialCan detect mixed-aggregation patterns from formula text. Cannot judge intent.
Calculations commented with business logicPartialCan detect absence of comments in formula text (if formula starts immediately with no // lines). Cannot verify comment quality.
Unused fields hidden, unused calcs deletedYeslist-available-fields cross-referenced with usage. Note: agent cannot delete calcs (platform limitation).
Field names are meaningfulPartialCan flag default-pattern names or very short/generic names (e.g., "Field1", "Calc1"). Cannot judge business meaning.
Field "Comments" populatedPartiallist-available-fields with verbosity:full may expose description/comment metadata. Coverage varies by datasource type.
Default data types set correctlyPartialCan detect type from field metadata. Cannot judge if the default is correct for the business context.
Default aggregation setPartialCan see default aggregation. Cannot judge if SUM vs. AVG is correct for the measure's semantics.
Default format set (number, date, currency)NoFormat strings not reliably exposed via current tools.
Default color/shape setNoNot exposed via current tools.

Dashboard(s): Style & Formatting​

CheckDetectable?Method / Limitation
Each dashboard has a descriptive titleYesget-workbook-inventory returns title metadata. Flag blank or auto-generated titles.
Instructions/metric definitions/helper text includedNoCannot inspect text objects on dashboards. Advise user to verify.
Extra borders, grid lines removedNoVisual-only. Cannot inspect formatting via tools.
Labels or axis included for all chartsNoCannot verify axis/label visibility. Advise user.
Color use is thoughtful and consistentNoCannot inspect color encoding. Recommend accessibility review.
Shape use is thoughtful and consistentNoCannot inspect shape encoding.
Tooltips formatted and consistentPartialCan detect tooltip fields via get-summary-data (fields on Detail). Cannot verify tooltip formatting.
Measures formatted appropriatelyNoFormat strings not exposed.
Font hierarchy clear and consistentNoVisual-only.
"Command" options removed from tooltipsNoCannot inspect tooltip configuration. Advise user to right-click > Tooltip > uncheck "Include command buttons."

Dashboard(s): Filters & Interactivity​

CheckDetectable?Method / Limitation
Actions work as designed and filter appropriatelyNoCannot simulate mark selection or trigger filter actions (platform limitation: no mark-selection command). Advise manual testing.
Parameters and Sets function as designedNoCannot change existing parameter values (author-parameter is create-only, caption collision on existing). Advise manual testing.
Logical model not excluding data unintentionallyNoRequires domain knowledge of expected results.
Context filters used where needed with LOD calcsPartialCan detect LOD calcs from formula text. Cannot verify context filter placement (no Filters shelf access). Advise user.
Filters function as designedNoCannot trigger filters. Advise manual testing.
Filters apply to all applicable sheetsPartialCan see filter-related fields across sheets but cannot confirm filter scope configuration.
Filter options customized (All option, Apply button, Relevant Values, selection type)NoFilter UI configuration not exposed via tools. Advise user to verify each filter's settings.

Usability​

CheckDetectable?Method / Limitation
Views render in <5 secondsNoCannot time rendering. Advise Performance Recorder.
Instructions/definitions easily foundNoVisual layout judgment.
Filters, legends, labels appropriately placedNoCannot inspect dashboard zone layout.
Export formatting (PDF, PPT, Excel) worksNoCannot test export. Advise manual verification.
Dashboard sizing compatible with common screensPartialCan note if dashboard exists (from inventory) but cannot read its size setting. Recommend fixed 1400x900 or similar.

Compliance & Maintainability​

CheckDetectable?Method / Limitation
Row Level Security (RLS) configuredNoServer/Cloud-side. Remind user.
Workbook permissions model setNoServer/Cloud-side. Remind user.
Branding appliedNoVisual inspection only.
Confidentiality statements includedNoCannot inspect text objects.
Auditability and versioning planNoOrganizational process. Remind user.
ETL/data lineage documentedNoExternal documentation. Remind user.
Entry criteria clearNoExternal documentation. Remind user.
Query and refresh duration stableNoRequires monitoring over time. Remind user to check post-publish.
Hard-coded values not used (e.g., date filters)PartialCan detect calcs with literal date values (e.g., #2024-01-01# or "2024") from formula text. Cannot detect filter hard-coding.
Calculations performed in ETL where applicableNoArchitectural judgment. Remind user.

Knowledge Transfer & Documentation​

CheckDetectable?Method / Limitation
Developer comments in workbookNoNot exposed via tools.
Calculation comments presentPartialCan detect // comment lines in formula text.
Dashboard layer namingNoCannot inspect container/zone names.
Color-coded workbook tabsNoTab color not exposed.
Naming conventions consistentYesCan scan all sheet/dashboard/field names for patterns.
Unused worksheets deletedYesCross-reference sheets against dashboard membership (existing Category 4).
Worksheets on dashboards hiddenPartialCan detect sheets placed on dashboards, but cannot verify the "hide sheet" setting is toggled. Advise user.
Containers used, extra containers removedNoCannot inspect dashboard container structure.
Action naming clearNoCannot read action configuration. Advise user.
Actions apply as designedNoCannot trigger actions (mark-selection gap). Advise manual testing.
