# Example: Fully Clean Report

This is the literal, complete output shape for a workbook with zero findings. Copy this
structure exactly — substitute the real workbook name, date, allow-list count, and
sheet count. Do not omit any section, do not add narrative, do not mention terminology
consistency or any other out-of-scope observation.

## What this example demonstrates

- The Findings summary block with all four counts (even at zero) is never dropped, regardless of how "obviously clean" the workbook is.
- Every severity tier gets its own heading with "None" stated explicitly — headings are never skipped.
- "Not Scanned" and "Allow-list suggestions" always appear, even when empty.
- No terminology-consistency asides, no "worth your attention" notes, no offers to widen scope, no editorializing. If something like that comes to mind while scanning, it does not belong in this report — leave it out entirely.
- No tool names, MCP call sequencing, or internal mechanics anywhere in the output.
