# Notional Directory Structure

A concrete example of the repo layout: three skills, one MCP server, one bundled Claude plugin, the per-harness adapters, the Docusaurus site, and governance/CI. The presentational companion is named `description.md` (use `description.mdx` where JSX components are needed).

## How the two files per item relate

The portable file stays minimal so every harness ingests it cleanly.

`skills/pdf-extract/SKILL.md`:

```markdown
---
name: pdf-extract
description: Extract text and tables from PDF files and fill forms. Use when working with PDFs, document extraction, or form filling.
---

# PDF Extract
## Quick start
Run `python scripts/extract.py <file.pdf>` ...
```

The companion holds everything the detail page needs, and never repeats the instructions (the generator embeds `SKILL.md`).

`skills/pdf-extract/description.md`:

```markdown
---
title: PDF Extract
type: skill
category: documents
tags: [pdf, extraction, forms]
level: beginner
version: 1.2.0
author: your-org
license: MIT
harnesses:
  - { id: cursor,  support: native }
  - { id: claude,  support: plugin }
  - { id: codex,   support: native }
  - { id: copilot, support: native }
  - { id: windsurf, support: native }
requirements: [ "python>=3.10", "pdfplumber" ]
install:
  cursor: "Symlinked via .cursor/skills; no action needed"
  claude: "/plugin marketplace add your-org/agent-skills-hub"
usage: "Ask: 'extract the tables from report.pdf'"
media: [ assets/hero.png, assets/demo.gif ]
links: { source: skills/pdf-extract, issues: "https://github.com/your-org/agent-skills-hub/issues" }
---

## Overview
Pulls clean text and tables out of PDFs...
