# Matching Intelligence Reference

Synonym table and contextual inference examples for expanding and interpreting user queries.

| User term | Also match |
|---|---|
| sales | revenue, orders, bookings, ARR, MRR |
| customers | clients, accounts, users, subscribers |
| churn | attrition, retention, cancellation, lost |
| profit | margin, earnings, net income, EBIT |
| pipeline | funnel, opportunities, deals, prospects |
| performance | KPIs, metrics, scorecard, health |
| trend | over time, time series, historical, monthly, weekly |
| region | geography, territory, area, market, location |
| product | SKU, item, catalog, offering, category |
| employee | headcount, staff, team, workforce, HR |

- "How are sales trending?" → Needs: date field + sales measure + line/trend chart capability
- "What's our customer breakdown?" → Needs: customer dimension + segmentation fields + aggregation
- "Show me marketing performance" → Needs: marketing-related measures (spend, impressions, conversions, ROI)
- "Revenue by product" → Needs: revenue measure + product dimension + comparison capability
